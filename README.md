# python-ai-study

这是我的 Python 基础学习代码仓库，主要用于记录跟随 B 站课程学习 Python 的过程，并为后续学习人工智能相关内容打基础。

## 当前内容

- Python 基础语法
- 变量、输入输出和类型转换
- 条件判断和循环
- 字符串、列表、元组、集合和字典
- 函数和 lambda 表达式
- 文件读写、CSV 和 JSON
- 异常处理
- 包和模块的基本用法

## 学习目标

1. 熟悉 Python 基础语法和常用数据结构。
2. 掌握文件读写、异常处理、模块和包的使用。
3. 为后续学习数据分析、机器学习和人工智能打好基础。
